# 版式与动效规格

全部默认值都在 `scripts/poem_video.py` 的 `DEFAULTS` 里，配置文件可逐项覆盖。

## 画布与分区

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 画布 | 1080×1440 | 3:4，小红书/抖音通用竖版 |
| `split` | 0.48 | 上半暖白区，下半照片 52% 全出血，无分隔线 |
| `bg` | `[241,241,239]` | #F1F1EF，上下同色，缺口与底色一致才像"少了一块" |
| 照片取景 | `photo_crop` 留空自动 | 自动按所需宽高比居中裁切 |

## 文字

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 字体 | Hiragino Sans GB W3 | 找不到时按 `FONT_CANDIDATES` 顺序回退，可指定 `font.path` |
| `size_ratio` | 0.032 | 34.56px ≈ 画布宽 3.2%；正文不是标题 |
| `line_height` | 1.88 | 多倍行距 |
| 文字块 | 上半区视觉居中 | 行宽由内容决定，脚本按行宽体检 |

**切片的垂直对位**：`ImageFont.getbbox()` 默认以"升部顶点"为原点，直接拿它算中线会让切片整体下沉半个字号（约 19px），看着就是"图和字错位"。必须 `getbbox("国", anchor="ls")` 取基线坐标系下的字盒，再把切片中线对齐字盒中线。

## 切片

| 项 | 默认 | 说明 |
| --- | --- | --- |
| `height_ratio` | 1.6 | 切片高 ≈ 1.6×正文字高（可用区间 1.4–2.0） |
| 显示宽度 | 由原图宽高比决定 | 控制在画布宽 5%–12%，上限 14% |
| `radius` | 3 | 2–4px 圆角，不描边、不投影 |
| 括号 | 脚本自动补 | 全角 `（ ）`，与切片之间留 `gap` |

## 原位取景框（不要挖空照片）

切片原位覆盖**半透明**暖白框，而不是实心矩形：`fill_alpha 95/255` + `edge_alpha 200/255` 的 2px 描边。这样照片始终完整可见，观众仍能看出"这块是从这儿取的"。透明框出现时从中心 0.55→1.0 快速展开。

## 动效（每块切片）

| 阶段 | 时长 | 内容 |
| --- | --- | --- |
| 拾起 `pick` | 0.14s | 原位放大 6%，像被拈起来 |
| 飞行 `fly` | 0.62s | 三次贝塞尔弧线（先向上离画 → 绕过文字上方 → 从下方切入位置），缓入缓出，峰值处 5% 方向拉伸 + 两层递减拖影 + 跟随切线的 ±6.5° 侧倾 |
| 落位 `settle` | 0.26s | 3.5% 过冲回弹 + 衰减摆动，像"咔"地卡进空格 |
| 间隔 `slice_gap` | 1.12s | 一块**完全落稳**后再停 0.1s 走下一块 |

动效的"生硬"通常来自三件事：直线平移、没有落位回弹、前后两块首尾相接不喘气。都已在默认值里处理。

## 片头结构

`cover_hold 0.80s`（成品画面定格，平台会把它当封面）+ `dissolve 0.25s`（叠化回"空括号 + 完整照片"）→ 正片。**第一帧不能是空场**：早期版本留了 0.2s 淡入，结果封面是一整块白。

片尾 `tail 2.20s` 定格成品。总时长 = 0.8 + 0.25 + (切片数 × 1.12 + 2.2) 左右（6 块 ≈ 9.9s）。

## 常调项

- 想更满栏：把诗句每行加长（脚本会报行宽）；不建议改字号，会偏离用户确认的观感。
- 想更快：调小 `slice_gap`，但不要小于 `pick+fly+settle`（=1.02s），否则会违反"一块落稳再走下一块"，体检会报出来。
- 每个切片在入诗尺寸下的放大倍率不要超过 1.3×：源图局部越小，放大后越糊；`slice.height_ratio` 调小或选更大的局部都能降倍率。
- 想要竖屏 9:16：改 `canvas` 并重设 `split` 与 `photo_crop`，其余参数照旧。

## 渲染管线

帧不落盘：`compose()` 出来的 RGB 直接写进两条 ffmpeg 的 stdin（cover 版先写定格与叠化帧，再写与无封面版共用的源时间轴帧），音频在同一个 ffmpeg 里用 `-af volume` 混入。这样 6 块切片的默认构建约 5 秒，磁盘上只留最终 mp4、封面图和一份临时 wav。需要逐帧检查时用 `build --dump-frames DIR`。
