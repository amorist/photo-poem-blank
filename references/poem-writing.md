# 读照片、写小诗

## 怎么"读"一张照片

先描述，再下笔。按这个顺序看：

1. **主体与视角**：人在哪、镜头站着还是蹲着、有没有被虚化的前景。
2. **光与天气**：顺光/逆光、白平衡偏暖还是偏冷、有没有雾。
3. **材质清单**：画面里能单独成词的东西——花瓣、水面、石头、栏杆、玻璃、灯光、手、影子、云、草。
4. **能一眼辨认的尺度**：同一个东西在 55px 高的小方框里还认得出来吗？太小、太糊、太素（一片均匀的蓝天）就不合格。

## 挑切片的三条硬标准

- **一个名词能命名**：说得出"这是水/这是岩/这是苔"，而不是"这是一块画面"。
- **缩小后仍可辨**：到 `inspect_photo.py --boxes` 的对比图里看真实尺寸，别猜。
- **彼此不同**：不要让两块都是石头、两块都是花。材质要拉开（天/水/石/绿/人），图像才有节奏。

默认让切片带一点"不完整"的真实感：可以是窄竖条、近方形或宽横条，但都要有明确对象。

## 诗句规则

| 项 | 要求 |
| --- | --- |
| 行数 | 3–4 行 |
| 正文字数 | 24–42 字（不含标点） |
| 人称时态 | 第二人称"你"，现在时 |
| 语气 | 克制、温暖、具体；不要形容词堆砌 |
| 结尾 | 最后一行轻轻转一下（"都借给了我""比云还安静"） |
| 行宽 | 每行 ≈ 画布宽 40–95%，长短交错更好看 |

## 空格纪律：图片即词

切片就是那个词，正文里不要再写一遍。这是最容易犯的错：

- ✗ `把{5}眼里的整个春天，都借给了我。`（{5} 已经是眼睛的近裁，"眼里"就把"眼"写了两次）
- ✓ `把{5}里的整个春天，都借给了我。`

同理：切片是「手」就别在附近再写"手"；切片是「蓝牌」就别再写"蓝"。写完把每个空格换成它的名词朗读一遍，读不通就改。

## 两个可复用的例子

**春日街头（人像、逆光、有交通牌与栏杆）**

> 风从{0}那边来，绕过{1}与{2}，
> 停在{3}上，你伸过{4}来，
> 把{5}里的整个春天，都借给了我。

切片：白花、蓝色路牌、红圈标志、橙色栏杆、手、眼。人像照片里，"眼"是最有情绪的一块，放在最后一行；不要让正文再出现"眼"。

**峡湾（风景、无人特写、有远处人群）**

> 云从{0}上慢慢滑下来，
> 落进{1}里，就再也没有出声。
> {2}抱着一点点{3}，
> {4}和云一起安静下来。

切片：远山、水、岩、苔绿、人群。风景照没有人物时，找一个"量级对比"的细节（远处的人群、船、一只鸟）当最后一块，诗就有了人味。

## 常见不合格

- 选了整片均匀的水面/天空/白墙当切片：缩小后是纯色块，读不出内容。
- 五块切片挤在同一个角落：取景框连成一片，画面失去平衡——在照片上分散开。
- 诗句说明照片（"这是一片大海"）：诗要写照片之外的关系（风、光、时间、你和我）。
- 一行太长挤满整幅（>95%）：换行，或删掉一个形容词。
